A high-density, premium technical portfolio and showcase of "quests" in **Geospatial Analytics**, **AI/ML**, and **Fullstack Engineering**. Built for **Aditya Vahlevy Nugraha**'s professional identity as the "Kura Ninja".

## 🚀 Featured Quests

- **GAIA (Geospatial Analytics Integrated Platform)**: A high-performance dashboard for agricultural data visualization, featuring hierarchical drill-downs (National to District), real-time soil nutrient monitoring, and interactive layer management.
- **SAM3 Playground**: An interactive full-stack dashboard for the Segment Anything Model 3, supporting image segmentation, model fine-tuning, and a robust polygon editor.
- **Yield Forecasting**: Satellite-imagery-based crop yield prediction using Sentinel-2 and deep learning (LSTM/GRU).

## ✨ Key Features

- **IDE-inspired Hero**: A unique terminal-like bio section with dynamic syntax highlighting.
- **Bento-box Dashboard**: High-density layouts for Spotify "Now Playing" and quick highlights.
- **Interactive 3D Cards**: Immersive project showcase with smooth Framer Motion animations.
- **Anti-AI Design**: A purposeful, opinionated design system with intentional spacing and unique typography.
- **Geospatial Mastery**: Deep integration with Deck.gl and MapLibre for large-scale data visualization.

## 🛠️ Tech Stack

- **Frontend**: Next.js 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4, Framer Motion, Radix UI
- **Runtime**: Bun
- **Icons**: Lucide React, Simple Icons, React Icons

## 🛠️ Getting Started

### Prerequisites

Ensure you have **Bun** installed on your system.

### Installation

```bash
# Clone the repository
git clone https://github.com/adityavhlvy/kura-ninja-client.git

# Install dependencies
bun install
```

### Development

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
